# PrivateVault Benchmark Methodology

## Agent Model

Agents are simulated decision makers with:
- Trust score
- Voting behavior
- Accuracy model

## Task Model

Each task contains:
- Ground truth
- Difficulty
- Impact

## Metrics

- Accuracy
- Agent count
- Coordination cost
- Variance

## Limitations

Current benchmarks are synthetic simulations and
do not yet model:
- Network latency
- Real LLM variance
- Byzantine adversaries
- Dynamic trust evolution

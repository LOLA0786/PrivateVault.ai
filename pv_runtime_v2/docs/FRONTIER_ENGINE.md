# Frontier Engine

Purpose:

Compute the minimum economically justified swarm size
for a governance decision.

Inputs:

- Trust
- Impact
- Latency
- Failure Risk

Outputs:

- Optimal Agent Count
- Utility Score

Observed Results:

- Adaptive swarm reduced coordination by ~51%
compared to a static 200-agent swarm.

Core Principle:

Maximize decision utility while minimizing
coordination cost.
